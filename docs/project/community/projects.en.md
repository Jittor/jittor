# Community project directory

[Section contents](index.en.md) · [中文](projects.md)

Projects from the existing Jittor community collection, grouped by task. This is not a compatibility
or maintenance-status certification. Check each repository for its requirements and current status.
For the maintained downstream integration repositories, see [JittorEcosystem](https://github.com/JittorEcosystem).

## Models and components

| Project | Purpose |
| --- | --- |
| [JittorLLMs](https://github.com/Jittor/JittorLLMs) | Large-model inference |

| [Jittor-Image-Models](https://github.com/Jittor-Image-Models/Jittor-Image-Models) | Image models |
| [Jittor-MLP](https://github.com/liuruiyang98/Jittor-MLP) | Vision MLP models |
