# Community

[Section contents](../index.en.md) · [中文](index.md)

Find projects by task in the [project directory](projects.en.md). For maintained
downstream integrations such as vLLM and Transformers, see [JittorEcosystem](https://github.com/JittorEcosystem).

Discuss usage in the [forum](https://discuss.jittor.org/); report reproducible defects in
[GitHub issues](https://github.com/Jittor/jittor/issues). Include the version, environment and minimal example.

See the [governance rules](governance.en.md) for project roles and decision-making.
