# Contrib API

[Section contents](index.en.md) · [中文](contrib.md)

`jittor.contrib` collects community-contributed algorithms and composition tools,
including connected-component labeling. Its stability is weaker than the core
API.

Select a utility by its input contract. For basic tensor operations, consult the core API first.
