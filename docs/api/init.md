# 初始化 API

[本栏目目录](index.md) · [English](init.en.md)

`jittor.init` 提供参数初始化方法，包括常量、均匀/正态分布，以及按扇入扇出缩放的
Xavier 与 Kaiming 系列。

用于显式设置参数的初始值。按模型结构选择方法，并核对传入张量的形状及 dtype。
