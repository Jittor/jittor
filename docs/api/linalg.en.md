# Linear Algebra API

[Section contents](index.en.md) · [中文](linalg.md)

`jittor.linalg` covers matrix decomposition, linear equation solving,
eigenvalue routines, norms, and Einstein summation.

Check dimensions, dtype and device requirements before solving or decomposing a matrix. Use the core API for general tensor operations.
