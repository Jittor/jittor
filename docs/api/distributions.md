# 概率分布 API

[本栏目目录](index.md) · [English](distributions.en.md)

`jittor.distributions` 提供概率分布族及其采样、对数概率和 KL 散度。

构造分布时区分参数形状、批次维度与事件维度；按具体分布说明选择采样和概率计算接口。
