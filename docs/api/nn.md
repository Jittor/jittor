# 神经网络 API

[本栏目目录](index.md) · [English](nn.en.md)

用 `from jittor import nn` 导入网络层与函数式算子。有状态的层在 `nn.modules`，
无状态的函数在 `nn.functional`。

定义模型时查找层、激活函数与损失的参数和输入形状。优化器与训练循环分别见下方链接。
