# 3D Loss API

[Section contents](index.en.md) · [中文](loss3d.md)

`jittor.loss3d` provides losses commonly used for point clouds and 3D geometry,
including Chamfer distance and Earth Mover's distance.

Use this page to choose losses for point-cloud or geometry tasks. Check each function’s point-set shapes, output convention and backend requirements.
