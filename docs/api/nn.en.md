# Neural Network API

[Section contents](index.en.md) · [中文](nn.md)

Import network layers and functional operators with `from jittor import nn`.
Stateful layers live in `nn.modules`, and stateless functions live in
`nn.functional`.

Look up layer, activation and loss arguments and input shapes when defining a model. Optimizers and training loops have separate guides below.
