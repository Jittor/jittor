# Dataset API

[Section contents](index.en.md) · [中文](dataset.md)

`jittor.dataset` provides dataset base classes and built-in datasets, and
handles batching, shuffling, and multi-process loading.

When preparing training data, look up sample loading, batch size and loader behavior. Image preprocessing lives in the transform API.
