# Data Transform API

[Section contents](index.en.md) · [中文](transform.md)

`jittor.transform` provides image preprocessing and data augmentation
transforms.

Apply these transforms before feeding data to a model. Check image types, channel order and value ranges so training and inference use consistent preprocessing.
