# Probability Distributions API

[Section contents](index.en.md) · [中文](distributions.md)

`jittor.distributions` provides probability distribution families together with
sampling, log probability, and KL divergence.

Distinguish parameter shapes, batch dimensions and event dimensions when constructing a distribution. Follow the specific distribution’s sampling and probability interfaces.
