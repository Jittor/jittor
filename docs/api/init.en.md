# Initialization API

[Section contents](index.en.md) · [中文](init.md)

`jittor.init` provides parameter initialization methods, including constant,
uniform, and normal distributions, as well as the Xavier and Kaiming families
scaled by fan-in and fan-out.

Use these methods to set initial parameter values explicitly. Choose a method for your architecture and check the tensor shape and dtype.

:::{autopublicmodule} jittor.init
:::
