# 流水式惰性执行

[本栏目目录](../index.md) · [English](pipelined-execution.en.md)

`auto_flush_ops` 让 CUDA 计算与 Python 构图重叠。提前发射可能降低延迟，也会让跨段中间值实体化、增加峰值显存。应在同一负载上同时测量时间和显存。

## 机制

`jt.flags.auto_flush_ops = N` 让待定图提前发射。每次算子构造都会计数；自执行器上次
运行以来累计创建了 `N` 个算子后，下一次 `VarHolder` 构造就把当前所有待定工作交给
执行器并返回，**不做设备同步**。设备开始算这一段，Python 继续建这一步的其余部分。

计数器锚定在每次 `Executor::run_sync` 上，所以训练循环里每一步的切分点位置相同，
每一段都编译出与上一步相同的融合 kernel。

惰性执行的语义被保留：

- **只有 Python 持有的值才是目标。** 没人持有的中间值仍然只在某个被持有的值需要它
  时才计算，段内的死代码消除与融合与之前完全一致；一个段边界最多让一个本可被后续
  消费者融合掉的中间值实体化。
- **flush 不嵌套**，而且执行错误绝不会从触发它的那次 `VarHolder` 构造里抛出。失败的
  flush 会挂起流水并把出错的算子留在待定状态，由调用方自己的 `sync` 抛出错误——和
  惰性执行下的行为一致；同步成功后流水恢复。
- **`jt.tape` 的输出永远不是 flush 目标。** `tape_together` 要在 `jt.Function.execute`
  跑完之后把这些算子接进 `Tapes` 节点，必须找到它们仍处于待定状态；`Tapes` 现在会
  断言这一点，而不是破坏 liveness 记账。

**这个开关只对 CUDA 生效。** CPU kernel 在调用线程上同步执行，提前发射只会在段边界
损失融合。

```{warning}
**它不是一个纯粹的调度旋钮。** 提前发射改变的是显存驻留，而 cuDNN 的卷积算法是
**实测候选者**选出来的——实测结果取决于当时显存里有什么。于是改动 `auto_flush_ops`
会改变卷积选中的算法，进而**改变梯度**（实测相对差 `3.8e-4`，确定性），而**前向的
loss 一位不差**。要可复现的训练数值，先 `jt.cudnn.set_benchmark(0)`。
详见[数值契约](../numerics/numerics-contract.md)。
```

## 选择阈值并测量

- `auto_flush_ops=0`：待定图保留到显式执行时机，调度器有更多机会释放中间值、融合计算。
- 正阈值：提前提交图段。阈值越小，边界越多，不保证更省显存。
- CUDA 默认值为 128。CPU 同步执行，不能从这种异步重叠中获益。

预热后比较 0 与原设置，保持输入、精度和 cuDNN 算法策略一致。用[性能分析](../../performance/profiling.md)记录整步延迟与峰值显存。历史模型的收益不能预测另一张计算图的收益。

若主机侧的 Python 或执行器工作占主导，调整阈值无法消除这部分工作。可进一步了解[静态图回放](../../development/runtime/static-graph-replay.md)如何复用兼容步骤的工作。模型内部的同步也会排空流水。


## 捕获中的外部调用

`graph_replay` 和 `capture_step` 只能重放原生图中记录的操作。直接使用指针写入输出、
启动外部内核或调用有副作用的回调时，调用方应在该操作前标记捕获边界：

```python
jt.graph_replay_barrier("external library launch")
```

捕获会报告拒绝原因，后续调用继续执行原函数。Torch `Tensor.data_ptr()` 和 Triton
桥接启动器自动标记这一边界；其余外部调用仍需显式标记。标记只影响当前线程中正在
构建的捕获，也会传递给嵌套捕获。在捕获外调用不会影响后续纯原生图。

已有原生 CUDA graph 正在记录时，显式与自动重放都提交普通惰性操作，由外层记录
拥有这些操作；不会在其中同步输入或再创建一层设备记录。

## 测量稳态步骤

用[基准测试](../../performance/benchmarking.md)计时，用[性能分析](../../performance/profiling.md)区分主机工作、设备工作与空闲。使用 nsys 时，按步切分预热后的时间线。整进程的 kernel 汇总混有编译、算法试跑和退出阶段，不能当作稳态对比。
