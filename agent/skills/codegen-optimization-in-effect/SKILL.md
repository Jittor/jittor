# 证明生成代码优化生效

## 操作

- 固定基线/候选源码、输入、编译器、目标架构和优化选项，分别预热并保存实际缓存路径。
- 检查生成源码确实包含候选变换，再检查 PTX/SASS 或宿主汇编；源码变化可能被编译器消除。
  搜索必须非空，区分 kernel 的不同实例，不从整个缓存任选命中。
- 核对真实编译命令，不把 `-Ofast` 与 `-O3` 当作同一配置。
- 先做输出和梯度参考，覆盖边界值、NaN/Inf 与相关 dtype。FMA 改变舍入次数，
  不能宣称必然逐位相等；按事先定义的误差合同判断。
- 分开记录 kernel 时间、launch/调度开销和端到端时间。按相同同步和预热口径交替 A/B，
  报告分布，避免把编译差异当收益。

若机器指令改变而性能不变，检查访存、寄存器、occupancy 和其它瓶颈。
一次机器上的测量不构成永久禁止某条指令的规则。没有目标硬件时只报告静态证据。
