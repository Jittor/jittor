# 证明多卡设备与资源归属

## 操作

1. 记录实际分配的设备、可见性映射及进程内逻辑 ordinal；通过 Jittor 公开机制切卡，
   不只直接调用 CUDA runtime 改变底层状态。
2. 对每张卡执行带独立数值参考的计算，并查 driver/runtime 的 pointer attributes。
   Var 的 `device_id` 或显存占用变化只能作辅助证据。
3. 从当前工具链发现库位置，不硬编码某个 `libcudart.so` 补丁版本或 SDK 安装路径。
4. 覆盖跨卡复制、有/无 P2P、异步生产者/消费者及切回原设备。事件创建、记录、等待和销毁的
   设备归属需一致；分配器释放应归还原设备池。
5. 用故意缺少排序的隔离负例验证竞态测试有鉴别力。没有 P2P 时隐式同步可能让负例仍成功，
   此时不能据此声称异步顺序安全。
6. 保留张量直到最后消费，验证完整进程退出与资源释放。另一张卡显存变化不必精确为零，
   driver 初始化、上下文和缓存都会影响统计。

使用实际可分配的设备运行，缺卡时明确未验证；不能把两次单卡运行当成跨卡验收。
