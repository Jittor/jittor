# 隔离并撤销进程级副作用

## 操作

- 在全新子进程对比导入前后的模块、环境、全局 flags、注册表和 hooks，确定副作用的唯一所有者。
- 将可选行为放在明确启用入口，记录旧值与安装对象；退出时只撤销自己安装的状态，
  不覆盖其它组件在期间作出的合法更新。
- 重复启用、嵌套启用、异常退出、提前关闭都应有定义。恢复原对象 identity，不只是造一个同值对象。
- hook 的包裹和解除按栈或所有权处理；共享状态使用与实际访问范围一致的锁，避免持锁回调或等待子进程。
- 不把未启用状态变成静默 noop：若 API 必须完成工作，缺少前提应给出可辨识失败。

测试用新进程检查 import 行为，用定向回归检查嵌套和恢复；不要在测试结尾手工重置所有副本
后声称实现能自动同步。配置读缓存需在不同子进程比较，不能在同一进程反复改环境假装 A/B。
