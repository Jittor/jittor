# 把同族修复变成可执行规则

## 操作

1. 从最小复现提取不变量：什么对象、什么阶段、禁止什么行为。先区分共有机制与局部例外。
2. 用 `rg` 找生产者、调用者和生成代码入口，列出必须扫描的根目录。不能只检查已知出错文件。
3. 按约束选择 AST、编译检查或行为测试。字符串出现只能证明文本存在；不要据此推断控制流或设备执行。
4. 扫描必须命中非空候选集；显式管理允许的例外，并让失效路径和无用豁免失败。
5. 在外部临时目录或独立 worktree 注入一个违反规则的例子，确认检查失败；恢复后确认通过。
   不在共享工作树用 `git checkout` 覆盖当前修改来做负向验证。
6. 给边界案例留回归：合法相似代码、重命名、新增文件和空扫描。报告规则覆盖范围，不将其等同于数值验收。

结构检查放 `tests/structure/`，规则涉及的行为仍用对应核心或 compat 测试证明。
基线与候选的来源检查见[隔离验证](../isolated-validation/SKILL.md)。
